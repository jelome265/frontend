# Original image assets

The SVG illustrations in this directory were created specifically for the Bean Boutique prototype. They are local, editable vector assets and do not depend on external image hosts.

- `bean-mark.svg` — brand mark and favicon
- `hero-pour-over.svg` — home page hero illustration
- `coffee-beans.svg` — coffee catalogue and promotional illustration
- `brewing-tools.svg` — equipment and brewing illustration
- `coffee-community.svg` — events and community illustration
- `grinder.svg` — grinder product illustration

Replace or supplement these prototype illustrations only with images that are original or appropriately licensed for reuse.
